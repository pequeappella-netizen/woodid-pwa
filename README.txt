WoodID PWA 0.9
Esta es una demo web móvil. Para usar cámara/selector de fotos desde un teléfono debe servirse desde HTTPS (o localhost).
La especie resultante es simulada. La foto elegida se muestra localmente y no se sube a un servidor.
Para publicarla: sube estos archivos a cualquier hosting HTTPS estático (GitHub Pages, Netlify, Cloudflare Pages, etc.).
